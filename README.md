# 🛡️ Android Security Scanner

A security analysis Android application developed by Sravani Bandreddy.

## 📥 Download

**[Download Android Security Scanner v1.0.0 (APK)](https://github.com/sravanibandreddy/android-security-scanner-downloads/releases/download/v1.0.0/app-release.apk)**

## ✨ Features

- Scan installed Android applications.
- Analyze selected APK files.
- Scan PDF files for security-related concerns.
- Generate and export scan reports.

## 📱 Installation

1. Download the APK from the link above.
2. Open the downloaded APK on your Android device.
3. Allow installation from this source if Android requests permission.
4. Tap Install.
5. Open Android Security Scanner.
